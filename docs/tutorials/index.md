# Mini-Tutorials

Small, self-contained mini-app tutorials for newcomers. Each one builds a tiny
working app — the same ones you can try live on the site's **Showcase** page —
and walks through exactly how it works, one concept at a time.

These tutorials are intentionally short. For the full picture, each one links
to the relevant chapter of the [Tutorial](../tutorial.md) or [Concepts](../concepts.md)
track.

## The mini-apps

- **[The Counter](counter-app.md)** — reactive component state, a `{count}`
  binding, and an `onclick` handler. The smallest possible reactive app, and
  where the whole mental model starts.
- **[The Todo List](todo-app.md)** — list state, the `for`/`in` loop binding
  with keyed reconciliation, and `bind` two-way input binding.
- **[Server Actions](server-actions.md)** — calling a Python function on the
  server from the browser with `@server_action` — the "from DB to DOM" story.
- **[The Theme Changer](theme-changer.md)** — the `$theme` store, design
  tokens, and `<ui-theme-provider>`: dark mode is one store flip away.
